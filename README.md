
# Reto técnico 03 - Agente de Órdenes de Compra SAP

Agente conversacional para preparar, validar y crear órdenes
de compra en un adaptador SAP simulado.

## Requisitos

- Node.js 20 o superior
- npm
- Git

## Instalación

```bash
npm install
```

## Ejecutar la demostración

```bash
npm run demo
```

## Desarrollo

```bash
npm run dev
```

## Compilación

```bash
npm run build
```

## Configuración

Consultar `.env.example`. La demostración debe funcionar
sin una clave de proveedor de IA.
